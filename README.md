# odin-recipes

## HTML Foundations, Project: Recipes

The focus of this project is on basic website creation and layout using HTML. CSS will be added in  
a future iteration. _odin-recipes_ has a homepage (index.html) and three recipe pages, each linked 
to via the homepage. Some basic practices include (but are not limited to):

- Unordered list creation
- Ordered list creation
- Inserting and formatting images
- Inserting and formatting links
- Creating headings and subheadings
